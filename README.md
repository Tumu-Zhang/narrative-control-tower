# narrative-control-tower

**长篇文档（硕博论文 / 专著 / 长篇技术报告）AI 协作生产的控制管线。**

AI 写长文档会自然滑向四种失控模式：**口径漂移**（多轮对话后同一参数出现多个版本）、**自产自检**（生产窗口自己写、自己查、自己入库）、**覆盖手改**（脚本重生成静默覆盖用户改过的文件）、**状态失真**（进度文档与磁盘实际脱节）。本仓库把一套实际运转两个多月、支撑六章硕士学位论文逐节生产的控制管线，整理成可直接装载复用的 Agent Skills。

## 仓库结构

```text
├─ skills/
│  ├─ paper-pipeline/        ← 主 skill：生产控制管线
│  │  ├─ SKILL.md            ← 总览：架构、十条硬约束、开工/收工
│  │  ├─ references/         ← 9 份操作手册（任务约束模板 / 窗口分离 /
│  │  │                        体检清单 / 状态看板 / 手改保护协议 /
│  │  │                        文献图表管理 / 技能调度 / 综述论证章指南）
│  │  └─ scripts/status_board.py   ← 状态看板脚本（--check/--write，通用版）
│  └─ empirical-chapter/     ← 配套写作 skill：试验数据章节写作手法
│     └─ SKILL.md
└─ 工程驾驭准备包/            ← v1 原始版（面向单一 AI 编码窗口的宪法式
                               准备包，保留作为管线思想的演化记录）
```

## 快速开始

1. **安装**：把 `skills/` 下的目录复制到你所用 Agent 平台的技能目录（如 Claude Code 的 `.claude/skills/`、兼容 Agent Skills 规范的 `skills/` 路径），或按平台说明注册路径。
2. **新项目初始化**：按 [`skills/paper-pipeline/references/01-项目工作树与初始化.md`](skills/paper-pipeline/references/01-项目工作树与初始化.md) 搭建工作树，先落"总指令＋执行日志＋状态看板"三件。
3. **日常运转**：每个窗口开工跑 `status_board.py --check`；写作/校核按窗口职责分离转达；收工执行"收尾三件套"。
4. **写作**：数据章节装 `empirical-chapter`；绪论/综述/讨论章按 [综述与论证章指南](skills/paper-pipeline/references/09-综述与论证章节.md) 接入外部开源论证技能（K-Dense scientific-writing 等，MIT；指路不打包，许可随原作者）。

## 核心思想速览

| 原则 | 一句话 |
|---|---|
| 约束是唯一口径 | 小节常设 `任务约束.md`，修订必须作者确认留痕 |
| 三级质量门控 | 草稿 → 校验 → 正文，未经校验的稿件拒绝入库 |
| 窗口职责分离 | 生产窗只写、校核窗只查＋登记，禁止单窗串全流程 |
| 磁盘是唯一真相源 | 状态看板由脚本按磁盘落位生成，`--check` 比对 |
| 用户手改最高优先级 | 覆盖前 mtime 复检＋全量 diff＋差异必问，严禁特征词抽查 |
| 错误史机制 | 每次失败留痕并升级为检查项，同项再犯提高权重 |
