# 09 综述与论证章节（绪论／文献综述／讨论）

数据章节之外，绪论、文献综述、机理讨论这类**论证型章节**同样走本管线的全部治理逻辑——框架审核门、任务约束、三级门控、窗口分离、收尾三件套一视同仁。本手册只讲**差异部分**：约束怎么改写、校核看什么、写作技能用谁的。

## 一、任务约束的综述章变体

沿用 [02-任务约束模板](02-任务约束模板.md) 的骨架，字段做三处适配：

| 字段 | 数据章节 | 综述/论证章节 |
|---|---|---|
| 唯一数据源 | 数据表＋资料 | **参考文献库汇总表**（正文引用唯一来源不变）＋范文学习目录 |
| 写作目的 | "用数据回答什么问题" | "研究现状梳理到什么深度、**研究缺口如何导出本文选题**" |
| 小节结构 | 按试验/方法分节 | **按主题脉络分节，不按文献罗列分节**；每节标注：本节主题、覆盖文献范围、与相邻主题的边界 |

写作目的里必须显式写出"缺口→选题"的逻辑链——综述章存在的意义就是让读者认同"这个缺口值得填"，缺了这条链综述就只是目录。

## 二、写作层：本 skill 不覆盖，引导接入外部技能

本仓库的 `empirical-chapter` 只管"数据→结果→结论"型章节；综述与论证写作请接入成熟的外部开源技能（**指路不打包**：保留各自许可与出处，接入方式统一为把 skill 目录复制到你的技能目录）：

| 技能 | 用途 | 来源与许可 |
|---|---|---|
| **scientific-writing**（K-Dense） | 引言/讨论的 IMRAD 写法、引用体例、报告规范（PRISMA 综述条目等） | [K-Dense-AI/claude-scientific-skills](https://github.com/K-Dense-AI/claude-scientific-skills)，MIT |
| **nature-academic-search**（wp-a） | 文献检索、去重、引用核验、题录导出——综述章的检索刚需 | [wp-a/nature-academic-search](https://github.com/wp-a/nature-academic-search)，MIT |
| nature-writing / nature-polishing 等社区系列 | manuscript 架构重排、学术英语润色 | 社区贡献系列（Yuan1z 等），**部分未随附许可证，接入前自行核验授权** |
| soul-writing 一脉的论证技能 | "从困惑写到论证"：张力建模、反模式清单、文献对话 | 无稳定公开仓库；可在各技能社区检索 "soul-writing / academic-writing 论证" 关键词按原作者页面获取 |

接入原则（与 [08-技能调度映射](08-技能调度映射.md) 一致）：

1. **真实加载**：写综述章前真实加载所选论证技能，口头声称"参考了规范"不算；
2. **许可自证**：二次分发任何第三方 skill 前先读其 LICENSE；未标注许可的一律不打包、只给链接；
3. **不得改头换面**：借用原则可以，复制文本去版权不行。

## 三、校核差异清单

综述章体检在通用清单（[04](04-体检校核清单.md)）之上，重点加查：

1. **覆盖与对话**：是"按主题组织观点、文献服务于论证"，还是"某作者做了什么"模板连排（AI 陈列式写作的典型病灶）；同段同型句式 ≥3 连排必改。
2. **缺口导出**：从现状到"本文做什么"的推理链完整，研究缺口有文献证据支撑，不是无据断言。
3. **引用密度与一一对应**：每条观点有出处；正文引用与文献汇总表逐条对应，无库外文献；叙述尽量表格化（作者/年份/方法/结论/与本作关系），少用大段文字陈列。
4. **时效与权威**：近 N 年文献占比、领域权威来源覆盖，由用户在约束中定标。
5. **AI 味**：综述章是模板化过渡语的重灾区，逐段过（见 04 第三节）。

## 四、管线照常运转提醒

- 综述章同样**禁节指向、禁占位**；图表（研究脉络时间线、文献计量图）同样按 [07](07-文献与图表管理.md) 一图一文件夹管理；
- 框架审核门前置：综述章的三级标题（主题划分）经确认后再动笔，主题边界返工代价远大于数据章节；
- 生产/校核窗口分离对综述章同样成立——AI 写综述的自我盲区（陈列不论证）恰恰最需要独立校核窗去戳破。
