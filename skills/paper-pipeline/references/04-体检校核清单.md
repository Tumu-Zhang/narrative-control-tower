# 04 体检校核清单

校核窗口对草稿执行体检时的完整维度清单。体检报告逐条列出"**位置—原文—问题—修改建议—优先级**"，优先级分：**P0 事实性**（数据/引用/口径错误）、**P1 论证与语言**、**P2 格式**。

## 一、内容与口径

1. 与 `03_文档框架/` 对应小节逐项对照：大纲列举项是否覆盖，缺项在报告中明示；综述性取舍须说明理由。
2. 口径一致性：参数、单位、术语与任务约束、上游章节完全一致；同义术语不混用；全称＋缩写仅在首次出现处定义一次。
3. 断言支撑：无文献或试验依据的绝对化措辞（"直接决定/根本原因/最广泛"）弱化或补引。
4. 链条自洽：材料/数据/方法的衔接关系闭环，读者无需跨节反推。
5. 数据缺口：以"待补充"占格的纯数据缺口**不作重点指正**（在 source_notes 跟踪）；但正文不得残留对话式流程语。

## 二、引用规范

1. 编号按正文首次出现**严格递增**、组内升序、无断号重复；同一文献节内只用首次编号。
2. 正文引用与参考文献表一一对应，无库外文献；调整段落须同步重排编号。
3. 点名式引用角标标于"（等）"之后，其余标于句尾；单作者文献不加"等"。
4. 草稿用右上角角标（Markdown `^[n]^`）；终稿由文献管理工具插域。
5. 表格中的引用不单列成列，标注于第一列单元格末尾。

## 三、语言与 AI 味（每项必查并记录）

- 模板化过渡语（"综上所述/值得注意的是/需要指出的是"）密度过高；同节同型收尾连发须消减；
- 句式单一：同段内"某作者＋研究内容＋表明"模板连排 ≥3 句须变换；
- 长句：单句 >100 字建议拆、>200 字必拆；
- 重复论断与高频词过度复现；口语化与内部工作用语；
- 目录预告式开头与空洞功效句；跨节元话语（"如前所述/某节已作表述"）；
- 绝对化无据断言；引号须用中文全角弯引号，不得残留半角直引号。

## 四、机检命令（交付前逐项跑、粘贴原始命中数）

```bash
# 1. 正文纯净度：流程注记残留（应为 0；模式按本项目流程语定制）
grep -nE "按用户口径|待用户核定|按.{0,6}确认口径|见 ?[0-9]\.[0-9]|详见|如前所述|前述|本节所述" 草稿.md

# 2. 内联引用编号残留检查（角标体例外）与断号检查
grep -noE "\[[0-9]+\]" 草稿.md | ...   # 提取首现序列，断言严格递增无重复

# 3. 半角直引号残留（应为 0）
grep -n "\"" 草稿.md

# 4. 图表编号连续性：提取 图x-y/表x-y 序列断言无断号
# 5. 数据节"段数＝图数＋表数"清点（见 empirical-chapter 硬约束）
# 6. 成图后占位残留（应为 0）；图片引用行 ≥1
```

机检是**下限不是上限**：机检全绿不代表体检通过，判断类维度（篇幅轻重、逻辑连贯、AI 味）仍须逐项人工过。

## 五、复核与整改报告

- 整改报告逐条记录"原表述 → 修改后"，末尾附整改后校验结果声明；
- 复核**逐项以实际文件内容独立验证**，不采信报告自述；声明与文件不符必须记录；
- 复核结论分：通过 / 有条件通过（列明条件项）/ 不通过（退回整改）。
